EBOU / QUESTIONS FRÉQUENTES

Questions fréquentes

Tout ce que vous devez savoir sur l’utilisation d’EBOU, la sécurité et la protection de vos données.

L’application EBOU est-elle vraiment gratuite ?

Oui, EBOU est 100 % gratuite. Publier une annonce, rechercher un objet et utiliser les fonctionnalités disponibles ne vous coûte aucun frais.

Comment se passe la restitution de l’objet ?

Pour votre sécurité, la restitution doit se faire au commissariat indiqué dans l’annonce. Les identités et les preuves de propriété peuvent être vérifiées avant la remise de l’objet.

Que faire si je trouve un objet sans connaître son propriétaire ?

Publiez une annonce « Objet trouvé » avec une description utile et le lieu concerné. Le système de rapprochement d’EBOU peut aider à identifier les annonces de perte correspondantes.

Mes données personnelles sont-elles en sécurité ?

EBOU est conçue pour protéger les informations personnelles. Évitez de publier des données sensibles dans les annonces et privilégiez toujours un lieu officiel pour la restitution.

Puis-je utiliser EBOU en dehors de Lomé ?

Oui. Vous pouvez utiliser EBOU dans d’autres villes du Togo. Précisez la ville, le quartier et les informations locales pertinentes lors du signalement.

Choisir la bonne version Android

EBOU Classic est prévu pour Android 11 et versions antérieures. EBOU Moderne est prévu pour Android 12 et versions ultérieures. En cas de doute, vérifiez la version Android dans les paramètres de votre téléphone.
